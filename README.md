# Home Remote

Android IR + Bluetooth remote, built on the phone with Buddy.

- **Samsung AC** (IR): power, temp, mode, fan, swing, Turbo, Quiet, WindFree, Eco, presets, sleep timer, Quick Settings tile
- **Hisense Google TV** (IR, NEC): touchpad, hold-to-repeat, apps, number pad, sleep timer
- **Zebronics Juke Bar 3900** (Bluetooth): media keys, 10-band EQ + limiter (DynamicsProcessing), bass/loudness/surround, TV volume over IR

Needs a phone with an IR blaster. Install / auto-update: add this repo in [Obtainium](https://github.com/ImranR98/Obtainium); new APKs are attached to GitHub Releases.
